Install

One file, nothing to set up

Download

Get PitzkiWidgets.exe from the Releases page.

Run it

It carries everything inside. Nothing else needs to be installed.

Say yes to Windows

The first time, Windows may say it "protected your PC", as it does for any app outside a store. Choose More info, then Run anyway.

Then click the icon next to the clock and choose Widgets… to pick your cards. The help pages explain every card.

Privacy

No account, no server

There is nowhere for the app to send anything about you. Each card reads only what it needs, and the few that go online send only their question: your city for the weather, the stocks you picked, your public Steam ID. What you copy is kept in memory only. Read exactly what each card reads.
